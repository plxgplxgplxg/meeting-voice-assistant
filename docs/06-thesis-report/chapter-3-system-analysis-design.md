# Chương 3: Phân Tích & Thiết Kế Hệ Thống

## 3.1. Phân Tích Yêu Cầu Phần Mềm
Đặc tả chi tiết các luồng nghiệp vụ và 5 ca sử dụng cốt lõi của hệ thống.

Mô hình kiến trúc microservices gọn nhẹ gồm Backend API, AI Service, và Frontend kết nối qua CSDL PostgreSQL + pgvector và hàng đợi Redis.

## 3.3. Thiết Kế Cơ Sở Dữ Liệu
Mô hình dữ liệu quan hệ kết hợp vector, cấu trúc chỉ mục HNSW phục vụ tìm kiếm ngữ nghĩa thời gian thực.
